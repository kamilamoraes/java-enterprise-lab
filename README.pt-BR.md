
# java-enterprise-lab

Um projeto Java de longo prazo que documenta o desenvolvimento de um sistema de gestão empresarial.

## Objetivo

Desenvolver um sistema de gestão empresarial em Java, aplicando conceitos de programação, orientação a objetos, arquitetura de software e práticas de desenvolvimento backend.

O projeto está sendo desenvolvido de forma incremental, acompanhando a evolução do meu aprendizado e incorporando gradualmente tecnologias e práticas utilizadas no mercado.

## Status do Projeto

🚧 Em desenvolvimento

Atualmente, o projeto contempla o gerenciamento de funcionários, clientes e produtos, com operações CRUD completas implementadas para os três módulos.

A próxima etapa de desenvolvimento está focada na persistência de dados, evoluindo a aplicação para além do armazenamento atual em memória.

## Funcionalidades Atuais

- Menu principal da aplicação
- Modelos de domínio para funcionários, clientes e produtos
- Criação de objetos utilizando construtores
- Encapsulamento com atributos privados, getters e setters
- Gerenciamento de funcionários com operações CRUD completas
- Gerenciamento de clientes com operações CRUD completas
- Gerenciamento de produtos com operações CRUD completas
- Atribuição sequencial de IDs aos registros cadastrados
- Validação de entradas nas operações de gerenciamento

## Roadmap

O projeto será desenvolvido nas seguintes etapas:

1. Estrutura Inicial
2. Gerenciamento de Funcionários
3. Gerenciamento de Clientes
4. Gerenciamento de Produtos
5. Persistência de Dados
6. Evolução Java Enterprise
7. Infraestrutura
8. Qualidade e Documentação

O roadmap poderá ser ajustado conforme a evolução do projeto e o surgimento de novos requisitos ou objetivos de aprendizado.
