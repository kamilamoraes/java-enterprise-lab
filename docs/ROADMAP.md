# Java Enterprise Lab Roadmap

## Objetivo

Desenvolver um sistema de gestão empresarial em Java com foco na aplicação de boas práticas de programação, arquitetura de software e tecnologias utilizadas no desenvolvimento backend. O projeto será evoluído gradualmente conforme o aprendizado e terá como objetivo simular um sistema utilizado no mercado.

---

## Observação

> Este roadmap representa o planejamento atual do projeto.
> Funcionalidades, tecnologias e prioridades poderão ser adicionadas, removidas ou reorganizadas conforme a evolução do desenvolvimento, do aprendizado e das necessidades do projeto.
